# Loan Default Risk Prediction using Explainable AI

## Project Overview

This repository contains the notebook implementation for a loan default risk prediction project completed as part of the **Human-Centred Artificial Intelligence Master’s programme at TU Dublin**. The project uses the **Home Credit Default Risk** dataset to build, compare, and explain machine learning and deep learning models for predicting whether a loan applicant is likely to experience repayment difficulties.

The main focus of the repository is the **Jupyter Notebook workflow**, including data exploration, preprocessing, feature engineering, model development, model evaluation, Explainable AI, and emerging AI techniques.

## Project Aim

The aim of this project is to develop a supervised binary classification model that predicts loan default risk using customer and loan application data. The project compares interpretable machine learning models with a neural network model and uses Explainable AI techniques to understand how predictions are made.

## Dataset

The project uses the **Home Credit Default Risk** dataset from Kaggle.
